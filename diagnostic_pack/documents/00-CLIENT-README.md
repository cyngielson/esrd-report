# CobolIQ Diagnostic Pack - Client README

**CobolIQ v0.8.2**

## What This Package Is

Source-cited evidence dossier for a COBOL system.
Static analysis only. Does NOT rewrite code.
Identifies structure, hotspots, return-codes, config candidates, modernization risks.
This package is intended to support modernization planning, not replace SME review.
