# Limitations

## What CobolIQ Does
- Static structural analysis of COBOL source
- Pattern-based extraction with source-line citation
- Deterministic complexity scoring

## What CobolIQ Does NOT Do
- Does not execute COBOL code
- Does not verify business correctness
- Current pack does not include JCL/DB2/VSAM/CICS infrastructure
- Does not produce a working modern equivalent

## Recommended Companion Activities
1. SME interviews - validate return-code meanings
2. Golden-output testing - freeze behavior before changes
3. Mainframe environment documentation
4. Copybook collection
